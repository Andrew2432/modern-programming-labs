ПІБ: Борисенко Андрій Сергійович

Група: 301-ТК

Номер варіанта: 4

Предметна область: Кінотеатр (Cinema Booking)

Версія .NET: 10



Система призначена для моделювання роботи кінотеатру та управління бронюванням квитків. Основні сутності включають фільми, зали, сеанси та безпосередньо самі квитки. Реалізовано можливість резервування та скасування місць на конкретний сеанс. Проєкт також враховує різні стратегії ціноутворення, наприклад, звичайні та студентські тарифи, забезпечуючи гнучкий розрахунок вартості.

Проєкт готовий до перевірки.
